# Personal Images Guide

This directory contains your personal photos and assets for the portfolio website.

## Required Images

### Main Photos
- `headshot.jpg` - Professional headshot for About page (recommended: 800x800px, square)
- `hero-photo.jpg` - Optional: Casual photo for hero section (recommended: 1200x800px)
- `about-photo.jpg` - Alternate photo for About page sections (recommended: 600x800px, portrait)

### Interests Photos (`/interests/` folder)
Add photos showcasing your personal interests:

- `anime-*.jpg` - Photos related to anime (figures, posters, conventions, etc.)
- `origami-*.jpg` - Your origami tessellation creations (recommended: high-res, well-lit)
- `cycling-*.jpg` - Cycling photos (you on bike, scenic routes, gear, etc.)
- `workout-*.jpg` - Gym/workout photos (optional, if you want to showcase fitness)

**Naming convention**: Use descriptive names like `origami-tessellation-1.jpg`, `cycling-route-mumbai.jpg`, etc.

## Image Specifications

- **Format**: JPG or PNG (will be optimized by Next.js)
- **Resolution**: High-res (1200px+ on longest side)
- **File size**: Try to keep under 2MB per image
- **Aspect ratios**:
  - Square (1:1) for headshots
  - Landscape (3:2 or 16:9) for hero images
  - Portrait (4:5 or 2:3) for about sections

## Next Steps

1. Add your photos to this directory
2. Update the filenames in the implementation as needed
3. Images will be automatically optimized by Next.js Image component

The website will use placeholder images until you add your personal photos here.
